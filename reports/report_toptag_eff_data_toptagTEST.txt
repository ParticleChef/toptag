============================================================
1. FORMULAS
============================================================
Per toptag/README.md, the data efficiency of an aggregated class
is the data yield with the OTHER classes subtracted, each scaled
to data by the pre-tag normalization alpha = N(Data)/N(MC):

  QCD-jet (gamma CR, gamma+jets sample, B-jet subtracted):
    eff_Data = [N(Data,tag) - alpha*SF_B*N(GJ,B,tag)]
             / [N(Data)     - alpha*SF_B*N(GJ,B)]

  Top-jet (ttbar CRs, B-jet AND QCD-jet subtracted):
    eff_Data = [N(Data,tag) - alpha*(SF_B*N(B,tag) + SF_QCD*N(QCD,tag))]
             / [N(Data)     - alpha*(SF_B*N(B)     + SF_QCD*N(QCD))]

  SF = eff_Data / eff_MC

SF_B = 1.0 +- 0.5 (no dedicated CR exists for the B-jet class).

--- Two Top-jet variants, both reported -------------------
The README's boxed eff_Data formula subtracts the RAW MC B/QCD
yields. toptag/docs/scalefactors.md argues the previously-derived
SF_QCD should correct that term (the AN's "QCDMistag" uncertainty
row would be meaningless otherwise), and scalefactors.py
implements it that way. The two readings disagree enough here to
change the sign of the answer, so BOTH are computed and plotted:

  raw        SF_B = SF_QCD = 1 in the subtraction
  corrected  SF_B = 1.0, SF_QCD from the gamma CR measurement below

ORDERING CONSTRAINT: the QCD-jet measurement must run first, since
the Top-jet corrected variant consumes its SF. The script enforces
this by construction (JOBS_QCD loop feeds sf_qcd to JOBS_TOP).

============================================================
2. HOW THE TWO HISTOGRAMS ARE COMBINED
============================================================
The measurement needs data yields (which only `fjpt` has) and
class-split MC yields (which only `fjpt_cat` has):

  fjpt      region x fjpt x TvsQCD            data + bkg
  fjpt_cat  + n_qinfj x n_binfj               bkg ONLY

fjpt_cat has no data because the truth quark / b-flavor matching
that defines the classes is undefined for data.

VERIFIED BEFORE USE: summing fjpt_cat over both class axes
reproduces fjpt bin-by-bin to machine precision (max relative
difference 3.5e-16) for every region and both TvsQCD bins, in
both files, and the two carry the same process keys. The two
histograms are therefore the same events and can be combined
directly.

CONSEQUENCE — AN EXACT IDENTITY. alpha is defined pre-tag over
ALL classes, so alpha * N(MC,all) = N(Data) exactly, per bin. The
Top-jet denominator therefore collapses:

  N(Data) - alpha*[N(B) + N(QCD)] == alpha * N(MC,Top)   (exact)

Confirmed numerically to 6e-15 relative. This is why the huge,
badly-normalized alpha of section 3 does NOT by itself wreck the
measurement: alpha rescales MC onto data, and it cancels in the
denominator. It does NOT cancel in the numerator, because
N(Data,tag) is a real measurement and is not equal to
alpha*N(MC,tag) — that difference is precisely the tagger
mismodeling the SF is meant to capture.

For the QCD-jet case only the GJ B-jet term is subtracted, so the
denominator is alpha*[N(MC,all) - N(GJ,B)], which the AN
approximates as alpha*N(GJ,QCD) (gamma+jets dominance). On this
file that approximation is good to 22%, 13%, 6%, 6% across the
four pT bins — the residual is the non-GJ processes, which are
17%, 11%, 5%, 6% of the gcr MC.

--- Uncertainties ------------------------------------------
Linearized propagation by one-at-a-time finite differences, same
convention and same uncorrelated-inputs caveat as
toptag/scalefactors.py's propagate(). Sources:
  stat       sqrt(variance) of every histogram term; data
             variance equals the data yield (unweighted Poisson)
  BJetMistag SF_B = 1 +- 0.5
  BJetNorm   50% normalization uncertainty on the GJ B-jet MC,
             folded into that term's sigma (QCD-jet job only)
  QCDMistag  the derived SF_QCD +- its own error (Top-jet
             corrected variant only)
NOT propagated: JES, QCD scale/PDF, parton shower, TopPt
reweighting — they need systematic-varied histograms that do not
exist in these files.

The "stat" figure in the breakdowns below is the same formula
re-propagated with ONLY the histogram sqrt(variance) terms; "syst"
is the quadrature remainder (SF_B, BJetNorm, QCDMistag).

SF error: sigma_SF/SF = sqrt[(sigma_Data/eff_Data)^2
                             + (sigma_MC/eff_MC)^2]
with sigma_MC the eff_MC error of report_toptag_eff_toptagTEST.txt
section 4. Its effect is negligible here (sigma_MC/eff_MC <= 2%),
so the SF values below agree with the previous version.

--- Correction (2026-09-23) --------------------------------
The previous version of this report had two errors in the
uncertainty treatment; the central values were not affected.
  1. The stat-only variant kept the B-jet sigmas WITH the 50%
     BJetNorm folded in, so that systematic was counted as
     stat. The QCD-jet breakdown in section 3 was therefore
     wrong (it read stat ~ syst). Fixed: stat now uses the pure
     histogram variance of the B-jet terms.
  2. SF error was sigma_Data/eff_MC only, ignoring the eff_MC
     error. Fixed as above.
The Top-jet breakdowns were not affected by (1): BJetNorm is
applied to the QCD-jet job only.

============================================================
5. WHY THE TOP-JET MEASUREMENT FAILS HERE
============================================================
Two compounding reasons, both visible in the yields.

(a) DATA TAGS FAR MORE OFTEN THAN MC. Tagged fraction,
    N(tagged)/N(total), pre-tag-normalized:

      pT [GeV]     Data     MC      Data/MC
       250-325    0.331    0.241      1.38
       325-400    0.359    0.233      1.54
       400-600    0.373    0.143      2.61
      >=600 (of)  0.267    0.073      3.65

    (tmcr and tecr separately give the same pattern.) After alpha
    normalization the MC underpredicts the tagged yield by up to
    3.6x. The subtraction attributes that entire excess to the
    Top-jet class, which inflates the numerator without touching
    the denominator.

(b) THE TOP-JET CLASS IS TINY IN THIS SAMPLE, so the denominator
    is a small residual of a large subtraction. Pre-tag class
    composition of the ttbar CRs:

      pT [GeV]    Top-jet   B-jet   QCD-jet
       250-325      7.6%    25.2%    67.2%
       325-400      8.1%    23.5%    68.5%
       400-600      4.3%    15.2%    80.5%
      >=600 (of)    1.0%     8.5%    90.4%

    The raw subtraction removes 92%, 92%, 96%, 99% of the data
    total; what is left is a 1-8% residual, and every percent of
    mismodeling in the 92-99% lands on it multiplied.

    The corrected variant scales the QCD-jet term — which alone
    is 67-90% of the MC — by SF_QCD ~ 1.25. The subtraction then
    removes 109%, 92%, 118%, 125% of the data total and the
    denominator goes NEGATIVE (-733, +602, -1509, -684 events).

A ttbar control region in which 90% of AK15 jets are pure-QCD
jets and 1% are top jets is not a ttbar control region. This is
the same defect already recorded in
report_toptag_eff_toptagTEST.txt section 7: classes 7 and 8 are
EMPTY in this file and the "Top-jet" class is almost entirely
class 6 (2 quarks + b), i.e. fully-merged hadronic tops are
essentially absent. The eff_MC measurement survived that because
it is a ratio WITHIN the Top-jet class; eff_Data does not,
because it needs the class to be a significant fraction of the
region.

NOT A CODE BUG. The same code path, with the same alpha
machinery and the same error propagation, gives a clean result
for the QCD-jet class in section 3, where the target class is
~85% of the region instead of ~5%.

============================================================
6. CAVEATS — READ BEFORE USING THESE NUMBERS
============================================================
- DO NOT USE ANY TOP-JET NUMBER IN SECTION 4. They are
  unphysical. They are reported so the failure is on record and
  reproducible, not because they mean anything.

- THE QCD-JET NUMBERS ARE PLAUSIBLE BUT NOT VALIDATED. The
  alpha cancellation (section 2) protects the ratio. The
  gamma+jets MC in file (b) is only 1.9e-03 weighted events in
  the lowest pT bin, but that is a normalization artifact: the
  effective MC statistics are 67k+ events (see
  report_toptag_eff_toptagTEST.txt section 7), and the error is
  dominated by the B-jet subtraction systematics anyway (section
  3). Treat SF ~ 1.0-1.3 as a test-sample result, and note it
  sits a factor ~2 below the AN's Run 2 ballpark of 2-2.5.

- UNCERTAINTIES REMAIN INCOMPLETE. Only stat, SF_B, BJetNorm and
  QCDMistag are propagated. The AN's dominant systematics for
  these SFs (final-state PS, TopPt reweighting, JES) are absent,
  so the quoted errors are lower bounds. The inputs are also
  treated as uncorrelated although the tagged yields are subsets
  of their own totals.

- THE TWO MEASUREMENTS COME FROM DIFFERENT TEST FILES, and the
  Top-jet corrected variant consumes an SF_QCD derived in the
  other one. Legitimate in the real pipeline (different regions,
  same year); here it crosses two unrelated test samples.

- THE RAW vs CORRECTED AMBIGUITY IS UNRESOLVED. On this sample
  it flips the sign of the answer, so it cannot be settled here.
  Settle it on the full sample, where the subtraction should be a
  small correction rather than 92-125% of the total.

- alpha IS STILL BROKEN IN ABSOLUTE TERMS (1e1-1e7 instead of
  O(1)) — see report_alpha_toptagTEST.txt section 5. It cancels
  in the denominator but the sample it comes from is still a few
  files normalized as if it were the full dataset.

- The overflow bin is drawn with a right edge of 1000 GeV. Do
  not read its width as a real pT range.

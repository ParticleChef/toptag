HOW TO RUN
============================================================
The script lives in toptag/studies/ and is standalone: no
arguments, no notebook, no manual function calls. It can be run
from ANY directory — it resolves its own paths against
toptag/ (/Users/hongjieun/working/toptag), where the .scaled
inputs live and where plots_effSF/ is written.

Use the plot_env interpreter — the system default Python 3.7
CANNOT read these .scaled files (pickle protocol 5).
Commands below are run from /Users/hongjieun/working/toptag:

  /Users/hongjieun/opt/anaconda3/envs/plot_env/bin/python \
      studies/plot_toptag_eff_toptagTEST.py

or activate the environment first:

  conda activate plot_env
  python studies/plot_toptag_eff_toptagTEST.py

Produces:
  plots_effSF/eff/<YEAR>/   (YEAR = 2022preEE here)
    5 plots (10 files, PDF + PNG)

Running a script creates plots_effSF/eff/<YEAR>/ if missing
and OVERWRITES the plots there in place, and prints its table to
stdout. To keep the printed table:

  /Users/hongjieun/opt/anaconda3/envs/plot_env/bin/python \
      studies/plot_toptag_eff_toptagTEST.py | tee eff_table.txt

The era is an optional command-line argument (default
2022preEE), e.g. `... studies/<script>.py 2023preBPix`. It
selects the input files (ERAS dict near the top of the script),
the luminosity label (LUMIS, same values as toptag/histmaker.py)
and the output sub-directory. To add an era, add an ERAS entry.
Results for 2023preBPix: report_toptag_effSF_2023preBPix.txt.

Histograms: efficiencies always come from fjpt_cat. alpha and the
data yields come from ERAS[era]["alpha_var"]: `fjpt_bin` for new
files (same pT edges as fjpt_cat), `fjpt` for these 2022 test
files, which predate fjpt_bin. The script stops with a message
if that histogram is empty or its pT edges differ from fjpt_cat.

Both input files must be present in toptag/ — the script
reads hadmonotop2022_toptagTEST.scaled for the Top-jet jobs and
hadmonotop2022_toptagTEST2.scaled for the QCD-jet job. To change
which regions or classes are measured, edit the JOBS dict near
the top of the script; the efficiency math is shared by every
entry and lives in one place.

Axes (5):

  fjpt     Variable     250, 325, 400, 600, 2000 GeV  (4 bins)

Storage: boost_histogram Weight -> .values() and .variances()
are both available, so uncertainties come from the stored
sum of squared weights, not from sqrt(N).

TvsQCD is the top-tag discriminant, WP = 0.33 (Run 3):
  bin 0 = untagged ("fail")
  bin 1 = tagged   ("pass")

n_qinfj = number of top-decay quarks clustered into the AK15 jet
          (dR <= 1.5 matching)
n_binfj = b-flavor found via ghost-hadron matching

3. JET CLASS DEFINITIONS (toptag/README.md)
============================================================
  n_qinfj | n_binfj = 0 | n_binfj >= 1
  --------|-------------|-------------
     0    |   class1    |   class2
     1    |   class3    |   class4
     2    |   class5    |   class6
     3    |   class7 (b-flavor ignored)
    >= 4  |   class8 (b-flavor ignored)

Aggregated calibration classes:
  QCD-jet = 1, 3
  B-jet   = 2, 4
  Top-jet = 5, 6, 7, 8   <-- measured in this report

PARTITION: the 8 classes are strictly disjoint and complete.
Verified three ways (see report_fjpt_toptagTEST.txt section 6):
  1. every (n_qinfj, n_binfj) cell belongs to exactly 1 class
  2. sum(8 classes) == inclusive total, all processes x regions
  3. all four flow bins are empty

Consequence used here: Top-jet yields and VARIANCES are plain
sums over classes 5,6,7,8 — no double counting, no covariance
term.

============================================================
4. WHAT WAS COMPUTED
============================================================
Top-tag efficiency for Top-class jets, as a function of the
AK15 jet pT:

              N(top-tagged, Top-jet)
  eff(pT) = --------------------------------
            N(top-tagged + untagged, Top-jet)

  numerator   = TvsQCD bin 1, classes 5+6+7+8
  denominator = TvsQCD bins 0+1, classes 5+6+7+8

ALL background processes are summed into both numerator and
denominator — the code iterates bkg["fjpt_cat"] directly rather
than a curated process list, so nothing present is left out.

Code: plot_toptag_eff_toptagTEST.py

--- Jobs --------------------------------------------------
The script is driven by a JOBS dict: each entry declares its own
input file, aggregated class, region list, process filter, axis
labels, y-range and grid spacing. The efficiency math and the
error formula live in one place and are shared by every job.

  eff_toptag_tmcr       (a) Top-jet  tmcr         all bkg
  eff_toptag_tecr       (a) Top-jet  tecr         all bkg
  eff_toptag_combined   (a) Top-jet  tmcr+tecr    all bkg
  eff_qcdjet_gcr        (b) QCD-jet  gcr          G + Jets only
  eff_qcdjet_gcr_zoom   (b) QCD-jet  gcr          G + Jets only

The request did not say which ttbar CR, so all three are made:
  tmcr     : t -> mu nu CR
  tecr     : t -> e nu CR
  combined : tmcr + tecr summed

For the QCD-jet job the class is QCD-jet = classes 1,3 and the
process loop is restricted to G + Jets alone (procs=["G + Jets"]),
not to all backgrounds. For the Top-jet jobs procs=None, meaning
every process in the file is summed.

Note that for QCD-jets eff is a MIS-TAG RATE: the fraction of
genuine QCD jets that pass the top tagger. Lower is better.

--- Uncertainties -----------------------------------------
Pass and fail are DISJOINT samples, so the error on
eff = P/(P+F) propagates as

  sigma_eff^2 = [ (1-eff)^2 * var_P + eff^2 * var_F ] / N^2

with var_P, var_F taken from the Weight storage. This is the
weighted-histogram generalisation of the binomial error; a
plain sqrt(N) binomial formula would be wrong here because the
entries are weighted.

--- x-axis ------------------------------------------------
The fjpt axis ends in a very wide 600-2000 GeV bin. It is drawn
as an OVERFLOW BIN closing at 1000 GeV: bin CONTENTS are
untouched, only the drawn right edge moves. The last point
therefore represents all jets with fjpt >= 600 GeV.

Observations:
- Efficiency rises monotonically with pT, ~0.67 -> ~0.87.
- The mu and e channels agree to better than 0.01 in every bin.
- The lowest pT bin sits essentially on the ~67% signal
  efficiency quoted in toptag/README.md for the Run 3 WP (0.33).
  (That value was drawn as a red dashed reference line in an
  earlier version of the plots; it was removed on request, so
  the comparison lives here in the text only.)
- The QCD-jet mis-tag rate is ~3-4%, mildly FALLING with pT,
  i.e. the opposite trend to the Top-jet efficiency. That is the
  right order of magnitude against the ~99% background rejection
  quoted in toptag/README.md for this WP.

7. CAVEATS — READ BEFORE USING THESE NUMBERS
============================================================
- THE SMALL ERRORS ARE GENUINE MC STATISTICS. (Corrected
  2026-09-23: an earlier version called them implausible.) The
  sums of weights are small (~10 for Top-jet, ~1e-3 for the
  lowest-pT QCD-jet bin), but the per-event weights are tiny
  too, so the effective MC statistics N_eff = (sum w)^2/sum w^2
  are large:
      pT bin                250-325  325-400  400-600  >=600
      Top-jet, tmcr+tecr     84k      90k      117k     27k
      mean weight            1.3e-4   1.2e-4   1.2e-4   1.4e-4
      G+Jets gcr, n_q<=1     67k      73k      1.5M     4.9M
  The binomial error sqrt(eff(1-eff)/N_eff) reproduces the
  quoted +/-0.001-0.003. The small sums of weights point to a
  NORMALIZATION problem (the same one that makes alpha >> 1, see
  report_alpha_toptagTEST.txt), not a statistics problem, and an
  efficiency is a ratio, so it is insensitive to that
  normalization. The errors are STATISTICAL ONLY: no
  systematics are included.

- THIS IS A 2-QUARK MEASUREMENT, NOT A MERGED-TOP ONE. In this
  file the Top-jet group is almost entirely class6 (2q, b);
  classes 7 (3q) and 8 (>3q) are EMPTY. Fully-merged hadronic
  tops are essentially absent, so "top-tag efficiency" here is
  really the efficiency on 2-quark jets. Confirm against the
  full sample before deriving scale factors.

- MC ONLY. fjpt_cat has no data (no truth matching for data), so
  this is the simulation efficiency eff_Sim — an INPUT to a
  scale factor, not a scale factor. SF = eff_Data / eff_Sim
  still needs the data-side measurement.

- All backgrounds are summed for the Top-jet jobs, not just
  ttbar. In the ttbar CRs TT and ST dominate the Top-jet class,
  but the denominator does include the other processes. If a
  ttbar-only efficiency is wanted, restrict the process loop.
  The QCD-jet job is G+Jets ONLY, by request.

- QCD Multijet and G + Jets are absent from file (a) entirely.
  This is why the QCD-jet job reads file (b).

- QCD-JET WEIGHTED YIELDS ARE TINY (1.5e-03 in the lowest pT
  bin, 0.56 in the overflow bin), but as in the first caveat
  this is normalization, not statistics: N_eff is 67k-4.9M. The
  statistical errors are sound; the mild pT trend (0.041 ->
  0.030) is statistically significant in THIS sample. Whether it
  survives on the full sample is a separate question.

- The Top-jet and QCD-jet numbers come from DIFFERENT test
  files. Their efficiencies may be compared; their absolute
  yields may not.

- The overflow bin is drawn with a right edge of 1000 GeV. Do
  not read its width as a real pT range.

- Small test file: absolute yields are not meaningful. The
  normalization caveat in report_fjpt_toptagTEST.txt section 4
  applies here too.
